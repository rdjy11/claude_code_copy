## 遗留观察项

- **需求 2362《ECU start up time》**：修复后同时出现在 `bt-nm` 与 `bt-platform` 索引中。多标签重叠本身是设计允许的，但 `bt-nm` 那条归属存疑，列为观察项。
- **时序类泛词**：`timeout` / `timing` / `latency` / `period` 使 `bt-uds` 收入较多纯时序条目（如「By-Pass Latency」）。设计文档 §4.4 已明确「时序/性能并入 `bt-uds` 与 `bt-diag-transport`」，属**设计意图**而非缺陷。
- **文档自身缺失**：gPTP Grandmaster 选举机制在规范中写作 `shall be implemented by TBD`（需求 1642），无实质内容可依。
