# APP UI 截图标注系统 Skill

## 适用场景

| 平台 | 示例 |
|------|------|
| Windows 应用 (.exe) | Electron 桌面端、WPF 应用、WinForm 程序、Flutter Windows |
| 安卓模拟器 APP | Android Studio Emulator、MuMu、蓝叠等模拟器中运行的 APP |

## 三大工作场景

| 触发信号 | 场景 | 执行路径 |
|---------|------|---------|
| 用户说"截图标注"/"APP标注"/"UI标注"，并提供了截图路径 | **A：为截图创建标注工具** | 见下方场景A |
| 用户说"帮我标注这个界面"，但没有截图路径 | **A2：引导用户截图** | 引导用户提供截图 → 再走场景A |
| 用户消息中含有 `"annotations":[` 且 `"source":"screenshot"` 的 JSON | **B：解析标注迭代代码** | 见下方场景B |
| 用户说"帮我标注"/"app annotate"，同时贴了截图 | **A3：有截图无路径** | 告知用户需提供截图文件路径（不支持直接分析贴图），引导保存截图文件后再标注 |

## 场景A：为截图创建标注工具

### 步骤

1. **确认截图路径**：用户提供截图文件完整路径（如 `E:\screenshots\app_v1.3_home.png`）
2. **检查文件**：Read 验证截图存在且为图片格式（.png/.jpg/.bmp）
3. **生成标注 HTML**：基于内置模板（见下方）生成一个可独立运行的标注 HTML 文件
4. **替换占位符**：将模板中的 `{{SCREENSHOT_PATH}}` 替换为实际截图路径
5. **保存并打开**：Write 到 `{{截图所在目录}}\annotate_{{截图文件名}}.html`，用浏览器打开
6. **附使用说明**：

> **使用标注工具：**
> 1. 工具已在浏览器打开，截图作为背景显示
> 2. 在截图上**拖拽框选**有问题的区域
> 3. 松开鼠标后输入备注（如"按钮颜色太暗，改为亮蓝色"），按 Enter 确认
> 4. 重复标注其他区域（每框选一次就输入一条备注）
> 5. 点右下角面板的 **复制 JSON**
> 6. 把复制的内容粘回对话，我会根据标注修改代码

### 标注模板

模板文件位于本 Skill 目录下的 `annotator-template.html`。核心功能：
- 加载本地截图作为全尺寸背景
- 支持拖拽框选区域，每个区域附带编号徽章
- 输入备注后生成标注记录
- 导出 JSON（含绝对像素坐标 + 百分比坐标，便于精确定位）
- 右侧悬浮 📌 按钮开关标注模式
- 右下角面板列出所有标注，支持复制 JSON 和清空

## 场景B：收到标注 JSON 后处理

**触发条件**：用户消息含 `"annotations":[` 且 `"source":"screenshot"`。

### JSON 字段速查

```
image_path    — 标注时使用的截图文件路径（用于确认修改对象）
image_size    — 截图尺寸 {width, height}
annotations[] — 标注数组
  id          — 标注编号（与截图上的红色徽章对应）
  x, y        — 框选区域左上角相对于截图的像素坐标
  width,height— 框选尺寸（像素）
  x_pct, y_pct— 百分比坐标（备用定位）
  comment     — 用户描述要修改的内容
```

### 处理规则

1. **识别修改目标**：根据 `image_path` 推测这是哪个页面/窗口的截图
2. **定位代码**：分析 comment 描述，找到对应的 UI 代码位置
3. **逐条修改**：按 annotation id 顺序，逐条修改代码
4. **边界处理**：

| 情况 | 处理 |
|---|---|
| JSON 格式损坏 | 回复"JSON 不完整，请重新点标注工具里的「复制 JSON」后再粘贴" |
| annotations 数组为空 | 回复"标注列表是空的，请先在截图框选区域添加备注" |
| 某条标注缺 comment | 跳过，末尾注明"标注 #N 无描述已跳过" |
| 无法从 comment 定位代码 | 回复标注编号 + 描述，询问"请确认这是哪个 UI 元素？" |

### 回复格式

修改完成后告知每条改动：

```
已根据你的 3 条标注完成修改：
① 标注 #1：登录按钮颜色从 #666 改为 #1565C0
② 标注 #2：标题字号从 16px 调整为 20px
③ 标注 #3：导航栏背景色加深为 #1a1a2e
```

## 场景A2：引导用户截图

若用户说"帮我标注这个界面"但未提供截图路径：

1. 回复引导文字：

> **请先截取 APP 界面截图：**
> - **安卓模拟器**：用模拟器自带的截图功能，保存为 .png 文件
> - **Windows 应用**：按 `Win + Shift + S` 截取窗口，保存到本地
> 
> 然后把截图文件路径发给我（如 `E:\screenshots\app_home.png`），我来生成标注工具。

2. 收到路径后走场景A

## 与 HTML 标注 Skill 的区别

| | prototype-redline (HTML) | app-ui-redline (截图) |
|---|---|---|
| 适用对象 | HTML 原型文件 | Windows .exe / 安卓模拟器 APP |
| 标注方式 | 注入 JS 到 HTML | 生成独立标注工具，加载截图 |
| 坐标参考 | 浏览器视口 | 截图像素 |
| 定位精度 | 精确到 DOM 元素 | 像素坐标 + 百分比 |
| 修改方式 | 直接修改 HTML/CSS | 根据 comment 定位源代码修改 |
