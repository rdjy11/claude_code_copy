# CHANGELOG

## v1.3.0 (2026-06-07)

### 🆕 新增章节
- **第4章 不定积分**（2节5知识点）：原函数、基本积分公式、第一类换元法（凑微分）、第二类换元法（三角代换/根式代换）、分部积分法（LIATE法则）
- **第5章 定积分与反常积分**（2节5知识点）：黎曼积分、牛顿-莱布尼茨公式、变上限积分求导、无穷区间反常积分（p-积分）、无界函数反常积分（瑕积分/q-积分）、比较判别法
- **第6章 多元函数微积分**（3节5知识点）：二元函数极限与连续、偏导数与全微分、多元极值（AC-B²判别）、拉格朗日乘数法、二重积分（直角坐标/极坐标）
- **第7章 无穷级数**（3节5知识点）：数项级数收敛判别（比值/根值/p-级数）、交错级数（莱布尼茨）、绝对/条件收敛、幂级数收敛半径、泰勒/麦克劳林展开、傅里叶级数
- **第8章 微分方程基础**（2节4知识点）：可分离变量、一阶线性方程（积分因子法）、可降阶高阶方程、二阶常系数齐次（特征方程法）、非齐次方程（待定系数法）

## v1.0.0 (2026-05-30)

### 🎉 首次发布
- **4 门学科**: 数学（微积分）、英语（CET6 词汇）、语文（必背诗文）、政治（马原）
- **内容驱动引擎架构**: 新增学科只需添加 JSON 数据文件
- **混合结构支持**: 三级结构（章→节→知识点）用于微积分/马原，二级结构（分类→知识点）用于词汇/诗文
- **Markdown + LaTeX 渲染**: 支持数学公式和富文本内容展示
- **选择题答题系统**: 选择→提交→结果反馈（正确/错误 + 解析）的完整交互流程
- **Hive 本地持久化**: 学习进度和答题记录本地存储
- **学习进度追踪**: 首页总进度环 + 各学科进度条 + 正确率统计
