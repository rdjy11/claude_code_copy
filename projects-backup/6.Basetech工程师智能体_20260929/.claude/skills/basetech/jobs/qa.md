# 工作流：问答（qa）

**用途**：工程师问「某功能 / 某服务的具体要求是什么」，答出结论并给出需求出处。

## 步骤

1. 读 `_index/meta-rules.md`——若问题涉及文档优先级，直接判定，不进专家
2. 按 `SKILL.md` 路由表判定涉及领域
3. 派发 **1–2 个**领域专家（命中多域时并行派发全部相关专家）
4. 汇总专家返回，写入产出文件

## 硬约束

- 每个结论**必须挂需求编号 + 标题 + 语料卷**；
- 无编号支撑的内容必须显式标注「**推断**」，不得与有依据的结论混写；
- 文档未覆盖该问题时，明确回答「**文档未覆盖**」，**禁止编造需求编号**；
- 语料编号存在正常跳跃（如 418–451 不存在），引用前须核对编号真实存在。

## 产出格式

写入 `_out/qa-<时间戳>.md`，内容为：

```
# 问答：<问题摘要>

**结论**：<直接回答>

**依据**：
- 需求 <编号>《<标题>》（语料卷 XX）—— "<原文片段>"
- ...

**推断**：<无编号支撑的部分；没有则写「无」>
```

多个领域专家各自作答时，按专家分节汇总，末尾如有跨域结论再补一节「综合」。
