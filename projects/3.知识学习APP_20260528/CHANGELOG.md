# CHANGELOG

## v1.1.0 (2026-05-31)

### 🆕 新增
- **CET6 词汇表完整导入**: 从《大学英语六级词汇表(全)含音标》导入 2983 个词汇，按 A-Z 分 25 章

- 每道习题包含：选词填空 + 4 个选项 + 正确答案 + 详细解析

### 📝 内容更新
- 每个单词包含：英文单词 + 国际音标 + 中英文释义
- 按首字母 A-Z 组织章节结构，支持快速浏览
- 习题来源标注权威词典出处（Cambridge、Oxford、Collins、Merriam-Webster、Longman、Macmillan）

### 🔧 技术变更
- `english_cet6.json` 从 8 词扩展到 2983 词（626 KB → 1159 KB）
- pubspec 版本号更新至 1.1.0+2

## v1.0.0 (2026-05-30)

### 🎉 首次发布
- **4 门学科**: 数学（微积分）、英语（CET6 词汇）、语文（必背诗文）、政治（马原）
- **内容驱动引擎架构**: 新增学科只需添加 JSON 数据文件
- **混合结构支持**: 三级结构（章→节→知识点）用于微积分/马原，二级结构（分类→知识点）用于词汇/诗文
- **Markdown + LaTeX 渲染**: 支持数学公式和富文本内容展示
- **选择题答题系统**: 选择→提交→结果反馈（正确/错误 + 解析）的完整交互流程
- **Hive 本地持久化**: 学习进度和答题记录本地存储
- **学习进度追踪**: 首页总进度环 + 各学科进度条 + 正确率统计
