### 2332 — Erase Memory routine "already erased" detection
- 版本：v1 ｜ 验证方式：Test ｜ 适用：通用 ｜ Legacy ID：72206v0

To reduce the overall software download time in case the memory is already erased when the ECU is delivered the factory. Table "Requirements for implementation of routines" - item 4 If the ECU is delivered to CEVT with the complete programmable memory already erased, the routine shall include an "already erased" detection in order to reduce the overall software download time. If the complete programmable memory is "already erased" and all other preconditions are met (e. g. SBL is downloaded and activated), the routine shall not perform any erase operation and immediately send a final positive response message with RoutineCompleted=1 (Routine is completed ). Once one or more bytes of the ECU programmable memory area has been programmed, the "already erased" status shall be invalidated. Any erase memory requests when the "already erased" status is invalid shall erase the requested memory area.

### 2335 — Transfer of DTC information to long term memory
- 版本：v3 ｜ 验证方式：Analysis ｜ 适用：通用 ｜ Legacy ID：72141v1

To ensure that no DTC information is lost during normal vehicle operation. Section "Transfer of DTC information to long term memory" If the ECU temporarily stores DTC information in short-term memory before storing it in long-term memory, any DTC information that has been added, deleted or changed during the operation cycle shall be transferred from short-term memory to long-term memory at the end of the operation cycle, and whenever required before it is erased from the short term memory if the erase is caused by normal vehicle operation. Situations/events, which are not regarded as normal vehicle operation, are:1) Unexpected disconnection of the ECU power supply while the ECU is in operation, due to Vehicle battery removal, fuse blow, connector disconnection or other similar cause which does not occur as part of normal vehicle operation.2) ECU supply voltage below minimum specification due to e. g. weak battery or other vehicle related fault.3) Diagnostic service requests that results in an ECU reset. See [Data_1] UDS Services, for services which are allowed to reset the ECU.4) Additional events, not covered by items 1-3 above, which have been documented by the implementer and approved by the responsible authority by OEM. DTC information from previous operation cycle shall be retained if temporarily stores DTC information in short-term memory is lost, in the current operation cycle, due to vehicle operation that is not regarded as normal.4.5.2.1.2.29 Requirements from section Clear DTC information
